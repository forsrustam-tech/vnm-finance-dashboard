# ВНМ — финансовый дашборд

Это доработанная версия дашборда. Теперь код разделен на понятные файлы:

- `index.html` — структура страницы.
- `style.css` — дизайн.
- `config.js` — стартовые данные и настройки Supabase.
- `app.js` — логика, расчеты, сохранение, импорт/экспорт.
- `supabase-schema.sql` — SQL для создания базы в Supabase.

## Как запустить быстро на своем компьютере

1. Распакуй архив.
2. Открой `index.html` в браузере.
3. Дашборд будет работать сразу.
4. Данные будут сохраняться локально в браузере.

Важно: в локальном режиме данные видишь только ты на этом устройстве. Учредитель на своем ноуте эти данные не увидит.

## Где менять стартовые данные

Открой `config.js`.

Там есть блок:

```js
window.DEFAULT_DATA = { ... }
```

В нем можно менять клиентов, расходы, выплаты, план и факт.

Но если дашборд уже запускался, браузер мог сохранить старую версию. Чтобы увидеть изменения из `config.js`, нужно зайти в `Настройки` → `Сбросить локальные данные`.

## Как включить Supabase

1. Создай проект в Supabase.
2. Открой Supabase → SQL Editor.
3. Вставь содержимое файла `supabase-schema.sql`.
4. Нажми Run.
5. Создай пользователей через Authentication.
6. В таблице `profiles` добавь роли пользователям:
   - `owner` — полный доступ.
   - `founder` — доступ к редактированию.
   - `viewer` — только просмотр.
7. Открой `config.js`.
8. Впиши данные проекта:

```js
window.SUPABASE_CONFIG = {
  ENABLED: true,
  URL: 'https://ТВОЙ-ПРОЕКТ.supabase.co',
  ANON_KEY: 'ТВОЙ_ANON_KEY'
};
```

После этого дашборд будет требовать вход по email и паролю, а данные будут храниться в Supabase.

## Как выложить на Vercel

1. Создай аккаунт GitHub.
2. Создай новый private-репозиторий.
3. Загрузи туда все файлы проекта.
4. Зайди на Vercel.
5. Подключи GitHub.
6. Выбери репозиторий.
7. Нажми Deploy.
8. Получишь ссылку на дашборд.

## Важное предупреждение

Не публикуй этот проект без Supabase Auth, если там будут реальные финансы. Просто HTML-ссылка без авторизации — это не кабинет, а объявление на подъезде.
