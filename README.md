# VNM — платформа агентства

Next.js + Postgres. Кабинеты команды с гибкими ролями, проекты клиентов,
выплаты таргетологам, обзор финансов для руководства. Meta Ads API — Фаза 2.

## Роли

Роли хранятся в БД (`roles`) и создаются/редактируются в разделе «Роли» —
у каждой роли набор прав: видит все финансы, управляет проектами,
управляет командой, управляет ролями. Роль «Владелец» системная и не
удаляется.

## Первый запуск

1. `npm install`
2. Скопировать `.env.example` в `.env.local`, заполнить `DATABASE_URL` и `AUTH_SECRET`
3. Применить `db/schema.sql` к базе
4. `npm run dev`, открыть `/setup` — создать аккаунт владельца (доступно один раз)
